# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, use GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/centennial-oss/react-ux-core/security/advisories/new).

We will acknowledge your report, investigate, and keep you informed of progress toward a fix.

## Supported versions

Only the latest published release receives security fixes.
